# 当前实现与追加约定（2026-11-04）
以下内容为原需求的补充及当前实现记录，原文保持不变。

## 一、项目结构与后端整合
- 原有 rtc_basic/ 仅作参考，保留原代码。
- 前端采用 React + Vite，位于 frontend/。
- 业务后台与 AI 后台已整合为同一个 Python FastAPI 进程，后台只需要打开一个终端，不再单独启动 8001 端口的 AI 服务。
- backend/main.py 为统一入口，处理 WebSocket 会话、上下文和任务生命周期。
- backend/ai_service.py 为 ASR、LLM、TTS 适配模块，由业务层在同进程内直接调用，不再通过内部 HTTP 请求连接另一个后台。
- 统一接口文档地址为 http://127.0.0.1:8000/docs；健康检查为 /api/health，AI 接口为 /api/ai/health 和 /api/ai/turn，实时会话为 /ws/call。

## 二、当前已实现的对话流程
- 使用 WebSocket 传递对话事件，支持拨打、挂断、文字发送、录音发送、对话气泡、逐字字幕及语音回复。
- 当前录音为完整单句提交识别：点击录音按钮开始，说完再次点击发送，最长 20 秒，音频上限 4 MB；暂未实现自动语音活动检测和逐音频帧流式识别。
- 语音处理流程为：浏览器采集音频 → 统一后台 ASR 识别 → LLM 生成回复 → TTS 合成 → 浏览器展示并播放。
- 文字输入跳过 ASR，直接进入模型回复流程。
- 当前逐字效果是在取得完整模型回复后分片展示，不是模型 token 流式生成。
- 每次会话最多保留 20 条上下文消息；挂断后取消后台处理、停止语音播放并释放麦克风。
- 录音期间禁用文字输入；处理回复及播放期间限制发起下一轮，避免对话重叠。
- 原需求中暂不实现的 RAG、知识库、向量数据库、课程咨询业务、多模态扩展和音色模拟仍不纳入当前实现范围。

## 三、配置与 Mock 行为
- 配置文件为项目根目录 .env，模板为 .env.example；服务密钥只保存在后台，不发送到前端。
- ASR、LLM、TTS 分别配置 BASE_URL、API_KEY、MODEL，三项齐全后对应阶段启用真实服务；允许不同阶段混合使用真实服务和 Mock。
- ASR 未配置时返回 MOCK_TRANSCRIPT 中的固定样例，不代表真实语音识别结果。
- LLM 未配置时返回演示回复；TTS 未配置时由浏览器 speechSynthesis 合成语音，需设备具备可用中文语音。
- 已配置的真实服务请求失败时显示错误，不自动伪装成成功的 Mock 结果。
- 真实服务预留 OpenAI 兼容接口：/audio/transcriptions、/chat/completions、/audio/speech；其他厂商协议在 AI 适配模块中扩展。
- 原 AI_SERVICE_URL 配置已不再使用。

## 四、本机与局域网访问配置
- 前端监听地址为 0.0.0.0，固定端口 5173，启用 strictPort；既允许本机访问，也允许局域网设备访问。
- 后台监听地址为 127.0.0.1，端口为 8000，仅供本机访问。
- 平板等设备不直接连接后台 8000；浏览器请求同一前端地址的 /api 和 /ws，再由 Vite 代理转发到本机后台。
- 0.0.0.0 和 127.0.0.1 是监听地址，5173 和 8000 是端口；0.0.0.0 监听所有 IPv4 接口，127.0.0.1 只监听本机回环接口。
- 当前电脑 WLAN 局域网 IP 为 10.253.255.121，本机可使用 localhost，局域网设备使用电脑 IP；平板上的 localhost 指向平板自身。
- .env 的 ALLOWED_ORIGINS 已包含本机及当前局域网 IP 对应的 HTTP/HTTPS 前端来源。后台每次 WebSocket 握手重新读取该配置，避免旧环境变量导致局域网连接被拒绝（403）。
- 电脑 IP 变化后，需要更新 ALLOWED_ORIGINS；HTTPS 使用的证书也需要包含新 IP。
- 防火墙需允许 TCP 5173 入站，建议仅限专用网络和本地子网；此前自动添加规则因 Windows 管理员权限不足未成功，实际规则状态以系统配置为准。
- 如有需要，可在管理员 PowerShell 中执行以下命令添加规则：

```powershell
New-NetFirewallRule -DisplayName "VoiceLink LAN 5173" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 5173 -RemoteAddress LocalSubnet -Profile Private
```

## 五、HTTPS 与平板录音
- 局域网 HTTP 可以进行文字对话，但浏览器麦克风录音需要安全上下文；本机 localhost 是浏览器允许使用 HTTP 录音的特殊情况。
- 已增加 HTTPS 启动模式，本机和局域网使用相同的 5173 端口，HTTP 与 HTTPS 模式择一启动。
- 已为当前 IP 10.253.255.121、127.0.0.1 和 localhost 生成本地开发服务器证书。
- 私钥及证书材料存放于 .certs/，公开 CA 证书位于 frontend/public/voice-link-ca.cer；这些生成文件已加入 Git 忽略，私钥禁止通过前端访问或对外分享。
- 当前服务器证书有效期为 180 天，CA 证书有效期为 365 天；过期或 IP 变化后需重新签发。
- 安卓 / HarmonyOS 平板可先在 HTTP 模式下载 http://10.253.255.121:5173/voice-link-ca.cer，再到系统设置中安装为“CA 证书”。不同设备的菜单名称可能不同，不应安装为 Wi-Fi 或 VPN 用户证书。
- 平板安装并信任 CA 后，将电脑前端切换到 HTTPS 模式，访问 https://10.253.255.121:5173，允许麦克风权限后录音。
- 安装 CA 会使设备信任该 CA 签发的证书，应妥善保管 CA 私钥；测试结束可移除设备上的该开发 CA。不以忽略证书错误代替正确安装信任。
- 前端已区分“不安全 HTTP 页面”和“浏览器缺少录音能力”的提示，避免将局域网 HTTP 限制误报为必须使用 localhost。

## 六、当前启动命令
在项目根目录启动统一后台：

```powershell
.\.venv\Scripts\python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload --ws-max-size 6000000
```

另开一个终端启动前端，HTTP 模式：

```powershell
cd frontend
npm run dev
```

需要平板录音时，先停止上述前端，再在 frontend 目录启动 HTTPS 模式：

```powershell
npm run dev:https
```

停止服务时，在对应终端按 Ctrl+C。后台只需要一个终端，前端另一个终端；无需再打开单独 AI 后台终端。
