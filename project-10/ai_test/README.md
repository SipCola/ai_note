# LLM 应用与 Agent 系统评测

从判断好坏到定位问题，用“电商导购＋购物车助手”串起评测思路。以大白话、虚构商品、模拟业务和少量原生 Python 为主。

贯穿案例：用户预算 300 元，找两款能装 15.6 英寸电脑且有现货的通勤包；看到推荐后，选择第二款加入购物车一个。商品尺寸和卖点来自知识库，当前价格与库存以业务接口为准。

整套教程围绕一条线：**明确目标 → 定义标准 → 准备考题 → 执行并留证 → 检查结果与过程 → 定位问题 → 修改后回归。**

## 真实豆包与七维评测

新增演示使用 `doubao-seed-2-1-lite-260915`：真实模型执行三轮购物任务，商品资料、价格库存接口和购物车全部 Mock。程序检查和独立的 LLM 语义评分结合，生成七维 JSON 与 HTML 报告。

逐个 case 交互运行，先启动本地工作台：

```powershell
python -B examples/seven_dimensions/server.py
```

打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)，选择用例后点击运行，查看对话、工具调用和七维结果。真实豆包模式会产生 API 调用；也可先选离线演示。

命令行也可以直接运行：

```powershell
python examples/seven_dimensions/run.py --probe
python examples/seven_dimensions/run.py --case normal
python examples/seven_dimensions/run.py --offline --all
```

运行方式、故障场景与指标说明见 [七维评测演示](./examples/seven_dimensions/README.md)。本地 `.env` 和生成的 `reports/` 均由 Git 忽略，示例配置见 `.env.example`。

结合真实记录学习判断依据、完整数据流、多轮检查及工具优化，见 [Case 1：电商导购七维评测解读](./Case1-电商导购七维评测解读.md)。

## 离线基础示例

示例只用 Python 标准库，使用模拟助手与模拟商品、购物车服务，不调用真实模型或真实电商。重点演示用户选中商品后的实时查询与加购检查。

在本目录执行：

```powershell
python examples/shopping_eval/run_eval.py --version baseline
python examples/shopping_eval/run_eval.py --version fixed
```

修改前的规则检查结果为 5/6，修改后为 6/6。它演示的是修复“加购接口明确失败，却报告已加入”这个错误。自然语言语义与商品召回仍需另外评测，数字不代表真实模型效果。

代码、用例和运行报告说明见 [实战示例](./examples/shopping_eval/README.md)。
