# 用 canvas-design 排版简历

`canvas-design` 是 Anthropic 发布的视觉设计技能。它的默认流程是先写设计构想，再输出 PDF 或 PNG。用它做简历时，可以借用字体、对齐、留白和视觉层级的原则，并在提示词里明确要求保留简历正文、导出文字可选中的 PDF。[技能源码](https://github.com/anthropics/skills/tree/main/skills/canvas-design)

## 安装

在 Codex 中发送下面这句话，即可让内置安装器从 GitHub 下载完整技能目录。

```text
$skill-installer 请从 https://github.com/anthropics/skills/tree/main/skills/canvas-design 安装 canvas-design。
```

本机安装后的入口为 `C:\Users\20112\.codex\skills\canvas-design\SKILL.md`。同一 Windows 用户下运行的本地 Cursor 也能识别这个目录，可以共用这份安装。[Codex 安装说明](https://learn.chatgpt.com/docs/build-skills) · [Cursor 技能目录](https://cursor.com/docs/skills)

如果只想让某个项目使用这项技能，可以把上游的整个 `canvas-design` 文件夹放到项目根目录的 `.agents/skills/` 下。Codex 和本地 Cursor 都会扫描这个项目目录。复制时保留 `SKILL.md`、`canvas-fonts/` 和 `LICENSE.txt`。[Codex 查找路径](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills) · [Cursor 查找路径](https://cursor.com/docs/skills)

## Codex 怎么用

1. 安装完成后开一个新对话，打开简历项目并附上简历初稿。需要按岗位调整时，再附上岗位描述。
2. 在 Codex CLI 或 IDE 扩展里输入 `$canvas-design` 选中技能，也可以用 `/skills` 查看可用技能。桌面端如果有技能选择菜单，可以从菜单选择。也可以直接说「请使用 canvas-design 技能」，或请 Codex 读取上面的 `SKILL.md` 路径。
3. 附上下面的简历提示词。如果技能安装后没有出现在列表里，重启 Codex 再试。[Codex 使用技能](https://learn.chatgpt.com/docs/build-skills#how-chatgpt-and-codex-use-skills)

## Cursor 怎么用

1. 在本地 Cursor 打开简历项目。在侧栏的 **Customize → Skills** 查看是否发现了 `canvas-design`。如果 Cursor 在安装前已经打开，重启后再查看。
2. 打开 **Agent** 聊天并附上简历初稿。在提示词开头写「请使用 canvas-design 技能」。如果技能列表里仍然没有，也可以请 Agent 先读取本机的 `SKILL.md`，或把完整技能目录放入当前项目的 `.cursor/skills/canvas-design/` 后重新打开项目。[Cursor Agent Skills](https://cursor.com/docs/skills)

## 可直接复制的简历提示词

```text
请使用 canvas-design 技能，为我附上的简历初稿排版。

输出一份中文 A4 PDF，尽量控制在一页，确保正文可以搜索、选择和复制。
采用清晰的单栏结构，通过字号、字重和留白突出关键经历。
保留原文和原有事实。空间不够时，先指出可以精简的段落。
导出后检查中文字体、换行、页边距和 PDF 文本提取效果。
```

如果想顺便针对岗位调整内容，可以附上岗位描述，把「保留原文」改成「根据岗位描述调整经历顺序和措辞，保留原有事实，缺少的数据标为待补充」。
